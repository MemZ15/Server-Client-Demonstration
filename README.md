# Boost.Asio TCP Client-Server Framework

A lightweight TCP client-server framework built in C++ using Boost.Asio.  
Designed for learning async networking, command dispatch systems, and session-based server architecture.

---

## Features

- TCP server with asynchronous accept loop
- Session-based client handling
- Command handler integration for extensible server logic
- Simple synchronous client for testing
- Clean separation between networking and command processing
